Upload any dataset

No required columns, fixed template or manual mapping. Upload any tabular CSV with a header row and data rows. SalesPulse detects dates, numbers and categories, then builds summaries and insights from the fields it finds.

No file selected

Uploads are temporary. Your original bundled dataset is preserved separately. After uploading, the Overview page shows insights from the new file; use “Remove uploaded data” on Overview to restore the original dataset.

No required columns

The uploader examines each column's values and infers whether it contains numbers, dates, categories or text. Examples of analyses it may generate:

Numeric fieldsTotals, averages, ranges, medians and distributions
Date fieldsTime coverage and monthly trends
Category fieldsMost common values and group comparisons
Text fieldsDistinct values, completeness and profile summaries
Data qualityBlank cells and duplicate rows
Interactive explorationClick chart values to filter other insights
What is the minimum?

A header row and at least one data row. There is no required column name, sales amount, date or category.

Sales-specific analysis

When familiar sales or CRM fields are present, SalesPulse also shows relevant sales KPIs. When they are absent, it does not invent them; it analyzes the available columns instead.
